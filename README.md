# Professional Portfolio

A personal portfolio website, together with its sitemap and wireframes. It presents who I am, what I can do, my work, and how to reach me.

## Pages

| Page | File | Purpose |
| --- | --- | --- |
| Home | `index.html` | Landing page and introduction |
| About | `About.html` | Background, education, and personal story |
| Gallery | `gallery.html` | Visual showcase of work and moments |
| Data | `data.html` | [Describe what this page shows] |
| Contact | `contact.html` | Ways to get in touch |
| Planning | `Portfolio sitemap and wireframes.html` | Sitemap and wireframes used to plan the site |

The planning stage produced a sitemap and wireframes. Screenshots of the pages and planning visuals are included in the repo:

## Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/2025bse188-crypto/Proffessional-Portofolio.git
```
2. Open the folder:
```bash
   cd Proffessional-Portofolio
```
3. Open `index.html` in any modern web browser.

No build step or dependencies are required.

## Features

- Multi-page layout with consistent navigation
- Responsive design that adapts to different screen sizes
- Media gallery with images and video
- Contact page
- Documented planning (sitemap and wireframes)
