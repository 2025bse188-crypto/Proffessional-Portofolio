## Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/2025bse188-crypto/Proffessional-Portofolio.git
```
2. Open the folder:
```bash
   cd Proffessional-Portofolio
```
3. Open `index.html` in any modern web browser.

No build step or dependencies are required.

## Features

- Multi-page layout with consistent navigation
- Responsive design that adapts to different screen sizes
- Media gallery with images and video
- Contact page
- Tables and lists
- Documented planning (sitemap and wireframes)
